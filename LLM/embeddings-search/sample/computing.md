# Computing

## Programming languages

Python emphasizes readable code and is widely used for data analysis and scientific computing.

Rust prevents many memory errors at compile time through its ownership and borrowing rules.

## Databases

SQLite is a self-contained SQL database engine that stores an entire database in a single file.

## HPC

Slurm is an open-source job scheduler that allocates compute nodes to jobs on HPC clusters.

## Embeddings

An embedding is a list of numbers that represents the meaning of a piece of text, so that texts with similar meanings have nearby vectors.
